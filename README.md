# Profitkit marketing site

Next.js 16 + Tailwind CSS 4 marketing landing for Profitkit.

## Dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- Tailwind CSS v4 (`@theme` tokens in `src/app/globals.css`)
- Fonts: Newsreader (display), DM Sans (body), JetBrains Mono (figures)

## Notes

- `index.legacy.html` is the previous static landing, kept for reference.
- Install CTAs are placeholders until the Shopify App Store URL is live.
